# Release scope

`paper-artifacts-2026-11-03-rc1` supplies the qualified F Windows and Linux main
executables from yanyanzheng96/VeriWorld-release. The task source retains the audited
parser-v4 scientific implementation, tests, fixtures, supporting data and
approved input-condition guide. Historical source and migration manifests
remain provenance records.

F replaces the prior bootstrap bytecode representation with specialized native
control flow. Independent source-blind authors still reconstructed the tested
Python loading and initialization boundary on both platforms. The experiments
do not establish a causal resistance improvement over D/E or unrecoverability.
The G prototype is paused and excluded from this release.

The defined F native checks pass on both platforms: reflection smoke plus eight
task-interface groups covering nine tasks, two state verifiers, six scripts,
three fixed task chains, two terminal consumers and six physics trajectories.
The task-interface checks cover PlaceOnBottom, BoxFold, MazeNavFPS, TunnelNav3D,
MovingShooter, LightWar, SceneGrounding, ObjectGrounding and Billiards.
Declared physics projections match the original, D and E reference results;
elapsed time is excluded. Windows screenshot/video consumers pass. Its variable
capture duration does not establish exact frame-count or pixel equivalence.

These checks are finite. They do not rerun every paper task, seed and model or
establish cross-platform score equivalence. Linux GPU graphics and complete
native teardown remain unqualified. Historical Linux GPU checks apply to their
recorded earlier binaries. See HARDENING_VALIDATION.json and RUNTIME_PROTECTION.md.

The historical supporting CSVs remain the audited parser-v4 export. Later model
runs and parameter-repeat campaigns are not silently included. In particular,
computational_physics_episodes.csv predates the later parser replacement
campaign and repeats. Infrastructure failures remain unscored, not valid model
failures. No benchmark score changes accompany this runtime release.

Original runtime packages, prior releases, source snapshots and failed checks
are retained. Existing project, Unreal Engine and third-party terms remain in
force. The per-scene asset-provenance inventory remains incomplete; this update
does not grant new rights over third-party content. Known fixture, target and
condition-label limitations remain in [KNOWN_ISSUES.md](KNOWN_ISSUES.md), distinct
from binary compatibility checks.
